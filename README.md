# Агент переливания компота

Практическое задание №4 по дисциплине «Интеллектуальные системы и технологии»: научить агента выравнивать объёмы в четырёх стаканах с минимальным числом подъёмов. Реализованы **Q-learning** и **SARSA** из лекций.

## Отчёт и результаты

- [REPORT.md](REPORT.md) — постановка, вопросы до программирования, формулы, основания из лекций и сравнение методов.
- [Кривые обучения](results/learning_curves.png) — награда в зависимости от числа эпизодов.
- [Доля оптимальных решений](results/optimal_rate.png) — проверка по точному минимуму подъёмов.
- [Скриншоты вывода программы и тестов](results/screenshots/) — с исходными текстовыми журналами.
- [summary.json](results/summary.json) — настройки и численные результаты.

Сохранённый эксперимент: **20 запусков по 60 000 эпизодов на каждый метод**. После обучения Q-learning находит минимум подъёмов во всех проверках, SARSA — в среднем в 89,72%. Оба метода выравнивают объёмы во всех итоговых проверках. Результаты относятся к дискретной модели ниже.

## Правила среды

Четыре стакана вмещают по 6 условных единиц. Всего компота 12 единиц, поэтому цель — по 3 в каждом стакане. Проверяются все 230 неравномерных начальных распределений целых объёмов.

Один шаг переливает одну единицу из источника в приёмник. Приёмники стоят на столе. Если источник остаётся в руке, переливание в несколько разных стаканов считается **одним подъёмом**. При смене источника предыдущий стакан ставится на стол, новый поднимается. Проливать и переполнять нельзя.

Награда равна `-1` за новый подъём и `0` за продолжение из того же источника. Поэтому сумма наград успешного эпизода равна минус числу подъёмов.

## Установка

Нужен Python 3.12+. Обучение использует стандартную библиотеку, Matplotlib нужен для графиков.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Все команды ниже выполняются из корня проекта.

## Обучить оба метода

```sh
# Полностью воспроизвести эксперимент
.venv/bin/python train.py

# Короткая проверка запуска, результаты в отдельной папке
.venv/bin/python train.py --episodes 1000 --seeds 2 --output smoke_results
```

По умолчанию используются `--episodes 60000 --seeds 20 --output results`. Каждый метод получает те же стартовые состояния для соответствующего seed. Во время обучения выводится прогресс по завершённым запускам. Повторный запуск перезаписывает файлы в указанной папке.

## Посмотреть действия готового агента

Стратегии первого запуска уже сохранены в репозитории. Повторно обучать их не нужно.

```sh
.venv/bin/python compote.py 5 3 2 2
.venv/bin/python compote.py 4 4 4 0 --policy results/sarsa_policy.json
```

Пример для Q-learning:

```text
Начало: (5, 3, 2, 2)
Стакан 1 в стакан 4: (4, 3, 2, 3), новых подъёмов: 1
Стакан 1 в стакан 3: (3, 3, 3, 3), новых подъёмов: 0
Готово. Подъёмов: 1
```

Можно задать любые четыре целых объёма от 0 до 6 с суммой 12. В выводе стаканы пронумерованы с 1; внутри кода — с 0.

## Перестроить графики

```sh
.venv/bin/python plot_results.py
```

Графики строятся из сохранённых CSV, без повторного обучения.

## Структура

- `compote.py` — правила переливания, выбор действий, Q-learning, SARSA и демонстрация стратегии.
- `train.py` — запуск эксперимента, журналы и сводка результатов.
- `plot_results.py` — графики по сохранённым результатам.
- `tests/test_compote.py` — физические ограничения, подсчёт подъёмов, точный минимум и сглаживание.
- `results/` — результаты, графики и читаемые JSON со стратегиями первого запуска.

В коде состояние — кортеж `(v1, v2, v3, v4, held)`, действие — пара `(source, target)`. Таблица `q[state][action]` хранит оценку действия. Номер стакана в руке нужен, чтобы отличать новый подъём от продолжения переливания.

```sh
.venv/bin/python -m unittest discover -s tests -v
```
